# .github

The GitHub organisation profile for livingbrain.wiki: `profile/README.md` is what
[github.com/Livingbrain-wiki](https://github.com/Livingbrain-wiki) shows.

`assets/org-banner.png` and `assets/org-avatar.png` are rendered from the brand sheet with the site's own brain
renderer (`brain.js`). Re-render them from `Livingbrain-wiki/website` (`tools/render-og.sh`) and copy them here.
The avatar is uploaded by hand at `github.com/organizations/Livingbrain-wiki/settings/profile`; GitHub has no API for it.
